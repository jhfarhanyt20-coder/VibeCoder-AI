      Browser Use

      What the agent can do in a browser. The built-in web tools work right away; browser control is one click away.

      Fetch a page
      Built-in. The agent downloads a URL and reads it as text — no browser needed.
      always on
      Search the web
      Built-in. The agent searches the internet and reads the results.
      always on
      Browser control (Playwright)
      Real browser control: open pages, click buttons, fill forms, read the DOM and take screenshots. The first start downloads the Playwright browser (~150 MB).
      Third-party desktop browser
      Some desktop apps ship their own browser plugin. It only works inside that app, so VibeCoder AI does not offer it here.
      not available here

      MCP Servers

      MCP servers connect the agent to more tools and data. Add a built-in server in one click, or your own.

      Built-in servers
      One-click presets. Written to the project config, or global when no project is open / “Global” is checked.
      Add server
      Local servers run a command; remote servers connect over HTTP. “Global” writes to the global config instead of this project.
      Configured servers
      –

      Skills

      Skills are step-by-step instructions the agent follows for a kind of task. Install a built-in one, import from GitHub, or write your own.

      Built-in skills
      Made for VibeCoder. Installed into the open project, or the global folder when no project is open.
      Import skills from GitHub
      Import public Agent Skills from a repository, a skills folder, or a direct SKILL.md URL. Imported files are read as instructions only and are not executed automatically.
      Only public GitHub repositories are supported. Review skill instructions before use.
