      Browser Use
      
              
      What the agent can do in a browser. The built-in web tools work right away; browser control is one click away.
      
            
      
          
      

          
      
            
      
              
      
                
      Fetch a page
      
                
      Built-in. The agent downloads a URL and reads it as text — no browser needed.
      
              
      
              always on
            
      
            
      
              
      
                
      Search the web
      
                
      Built-in. The agent searches the internet and reads the results.
      
              
      
              always on
            
      
          
      

          
      
            
      
              
      
                
      Browser control (Playwright)
      
                
      Real browser control: open pages, click buttons, fill forms, read the DOM and take screenshots. The first start downloads the Playwright browser (~150 MB).

      OpenCode also ships a browser plugin that attaches to the tabs of the OpenCode desktop app. It only works inside that desktop app, so VibeCoder AI does not offer it here.

      Memory
      
              
      Facts the agent keeps for itself — preferences, decisions and corrections it remembered. The agent writes these on its own, and you can edit or remove them here.

      When this is on, the agent reads the notes below when a topic comes up again — and it writes a new one ONLY when you tell it to (“remember this”). It never saves anything on its own.
